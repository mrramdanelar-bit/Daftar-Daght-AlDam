# دفتر ضغط الدم — مشروع Android

هذا مشروع تطبيق Android أصلي بلغة Java، يعمل دون اتصال بالإنترنت ويحفظ البيانات محليًا على الهاتف باستخدام SQLite.

## الوظائف
- إضافة عدة مستخدمين بأسمائهم.
- صفحة مستقلة لكل مستخدم وسجل قياساته.
- تسجيل قراءتين للضغط وحساب المتوسط تلقائيًا.
- تسجيل النبض والفترة والملاحظات.
- حذف قياس أو حذف مستخدم مع جميع قياساته.

## بناء APK
1. افتح مجلد المشروع في Android Studio.
2. انتظر مزامنة Gradle.
3. من القائمة اختر Build ثم Build APK(s).
4. ستجد ملف APK عادة في:
   `app/build/outputs/apk/debug/app-debug.apk`

يمكن أيضًا بناء نسخة Debug عبر GitHub Actions بعد رفع المشروع إلى مستودع GitHub؛ يوجد ملف workflow في `.github/workflows/android.yml`.

## تنبيه
التطبيق دفتر لتسجيل القراءات فقط، ولا يشخّص ارتفاع الضغط ولا يغيّر العلاج. لا تعتمد على قراءة واحدة لاتخاذ قرار طبي.
